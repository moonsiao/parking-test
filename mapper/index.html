How · 怎么用
1. Add a zone → Draw corners: click the corners in order, then Finish.
2. Add row: click the first spot, then the last spot, fill in count + start number.
3. Spots are spaced evenly between them. Wrong? Delete the row and redo.
先加区 → 点"画区的角"按顺序点每个角 → Finish。再"加一排"：点第一个车位、最后一个车位，填数量和起始号码。
